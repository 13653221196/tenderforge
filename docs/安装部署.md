# 安装与部署

本文覆盖 Windows 本机、Linux 服务器、Docker 三种方式，以及反向代理、备份与升级。

---

## 0. 环境要求

| 项目 | 要求 |
|---|---|
| Python | 3.10 及以上（3.11 / 3.12 / 3.13 均可） |
| 操作系统 | Windows 10/11、Ubuntu 20.04+、Debian 11+、CentOS 7+ 均可 |
| 内存 | 建议 2 GB 以上（解析大体积 PDF 时更吃内存） |
| 磁盘 | 500 MB 起，实际取决于上传的招标文件与导出件 |
| 网络 | 不联网也能跑（demo 模式）；接模型时需要能访问对应 API |

不需要 Node.js、不需要 Redis、不需要独立数据库服务。SQLite 内嵌。

---

## 1. Windows 本机

### 1.1 装 Python

到 <https://www.python.org/downloads/> 下载 3.10+，安装时**勾选 “Add Python to PATH”**。

验证：

```bat
python --version
```

### 1.2 装依赖

在项目根目录打开命令行：

```bat
python -m pip install -r backend/requirements.txt
```

国内网络慢可以换镜像：

```bat
python -m pip install -r backend/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 1.3 启动

**方式一（推荐）**：双击 `启动.bat`。它会先跑自检，再拉起服务。

**方式二**：命令行手动启动：

```bat
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 5210
```

浏览器打开 <http://127.0.0.1:5210>。

### 1.4 首次登录

第一次启动会自动建库并生成管理员：

- 账号：`admin`
- 密码：随机生成，写在 **`data/初始管理员.txt`**

打开该文件查看，登录后请立刻到「设置 → 企业与成员」改密码。

> 想指定初始密码，可在首次启动前设置环境变量 `BIDAGENT_INIT_ADMIN_PASSWORD`（至少 8 位）。
> 只在账号库为空时生效，已有账号的库不受影响。

## 2. Linux 服务器

### 2.1 准备

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip
```

### 2.2 部署

```bash
# 假设放到 /opt/bidagent
sudo mkdir -p /opt/bidagent
sudo chown $USER:$USER /opt/bidagent
cd /opt/bidagent

# 上传代码后创建虚拟环境
python3 -m venv .venv
.venv/bin/pip install -U pip
.venv/bin/pip install -r backend/requirements.txt
```

### 2.3 自检

```bash
.venv/bin/python -m backend.app.preflight
```

自检会检查依赖、端口、数据目录写权限，有问题会给具体的处理建议。

### 2.4 手动启动验证

```bash
.venv/bin/python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 5210
```

另开一个终端：

```bash
curl -s http://127.0.0.1:5210/api/health
```

返回 `{"ok":true,...}` 就说明起来了。

### 2.5 配成系统服务

创建 `/etc/systemd/system/bidagent.service`：

```ini
[Unit]
Description=BidAgent
After=network.target

[Service]
Type=simple
User=www
Group=www
WorkingDirectory=/opt/bidagent
Environment=BIDAGENT_PORT=5210
Environment=BIDAGENT_HOST=127.0.0.1
ExecStart=/opt/bidagent/.venv/bin/python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 5210
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

启用：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now bidagent
sudo systemctl status bidagent
sudo journalctl -u bidagent -f     # 看日志
```

> 用 `www` 用户跑之前，记得 `sudo chown -R www:www /opt/bidagent`，否则数据目录写不进去。

## 3. Docker

项目没有预置 Dockerfile，这里给一份可直接用的。

`Dockerfile`：

```dockerfile
FROM python:3.12-slim

WORKDIR /app

COPY backend/requirements.txt backend/requirements.txt
RUN pip install --no-cache-dir -r backend/requirements.txt

COPY . .

ENV BIDAGENT_HOST=0.0.0.0 \
    BIDAGENT_PORT=5210 \
    BIDAGENT_DATA=/data

EXPOSE 5210
VOLUME ["/data"]

CMD ["python", "-m", "uvicorn", "backend.app.main:app", "--host", "0.0.0.0", "--port", "5210"]
```

构建与运行：

```bash
docker build -t bidagent .
docker run -d --name bidagent \
  -p 5210:5210 \
  -v $(pwd)/data:/data \
  bidagent
```

**务必挂载 `/data` 卷**，否则容器一删，项目、知识库、账号全没了。

查看初始管理员密码：

```bash
docker exec bidagent cat /data/初始管理员.txt
```

## 4. 反向代理与 HTTPS

服务本身只监听 `127.0.0.1:5210`，对外请用 nginx 反代。

```nginx
server {
    listen 80;
    server_name your-domain.com;

    client_max_body_size 100m;   # 招标文件可能几十 MB，必须放大

    location / {
        proxy_pass http://127.0.0.1:5210;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 长任务（整本生成）容易超过默认 60 秒
        proxy_read_timeout 600s;
        proxy_send_timeout 600s;
    }
}
```

配 HTTPS 最省事的办法是 certbot：

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

> **对外提供访问前请务必配 HTTPS。** 登录态、企业数据、模型密钥都走这条链路。

## 5. 环境变量

配置优先级：**真实环境变量 > 项目根 `.env` > 默认值**。

把 `.env.example` 复制成 `.env` 再改，或直接在 systemd / docker 里注入。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `BIDAGENT_HOST` | `127.0.0.1` | 监听地址，容器里用 `0.0.0.0` |
| `BIDAGENT_PORT` | `5210` | 监听端口 |
| `BIDAGENT_DATA` | `./data` | 数据目录，建议放到独立磁盘并单独备份 |
| `BIDAGENT_ENV_FILE` | 空 | 指定另一个 .env 文件路径 |
| `BIDAGENT_INIT_ADMIN_PASSWORD` | 空 | 首次建管理员时用，至少 8 位 |
| `LLM_BASE_URL` | 空 | 模型接口地址，如 `https://api.deepseek.com/v1` |
| `LLM_API_KEY` | 空 | 模型密钥 |
| `LLM_MODEL` | 空 | 模型名，如 `deepseek-chat` |
| `LLM_MAX_TOKENS` | `4096` | 单次输出上限 |
| `LLM_TIMEOUT` | `120` | 请求超时（秒） |
| `LLM_WIRE_API` | 自动 | `chat` 或 `responses`，Codex 系列需要 `responses` |

模型也可以在界面上配（支持多模型、按环节分工），界面配置优先于环境变量。

## 6. 数据目录与备份

所有运行数据都在 `data/`：

```
data/
├── app.db              主业务库（项目、章节、检查、导出记录）
├── auth.db             账号与企业
├── basecore.db         基座数据
├── models.json         模型配置（含密钥，切勿外传）
├── embedding.json      向量检索配置（含密钥）
├── uploads/            上传的招标文件
├── exports/            导出的 Word
├── kb/                 企业知识库
└── 初始管理员.txt        首次启动的密码，阅后可删
```

**备份**：

```bash
python -m backend.ops.backup
```

会生成带时间戳的备份包并做完整性校验。

也可以直接冷备：停服务后 `tar czf backup-$(date +%F).tar.gz data/`。

**恢复**：停服务 → 解压覆盖 `data/` → 确认属主正确 → 启服务。

> `models.json` 与 `embedding.json` 里有明文 API Key。备份包请放在受控位置，不要传到公开仓库或网盘。

## 7. 升级

```bash
sudo systemctl stop bidagent

# 备份（重要）
tar czf ~/bidagent-data-$(date +%F).tar.gz data/

# 覆盖代码（保留 data/、.env）
rsync -av --exclude data --exclude .env --exclude .venv ./新版本/ /opt/bidagent/

.venv/bin/pip install -r backend/requirements.txt
.venv/bin/python -m backend.app.preflight

sudo systemctl start bidagent
curl -s http://127.0.0.1:5210/api/health
```

数据库结构变更在启动时自动迁移，不需要手工执行 SQL。

## 8. 常见问题

**启动报「读不到启动配置」**
用的是别的 Python。用 `python -c "import sys; print(sys.executable)"` 确认是装了依赖的那个解释器。

**端口被占用**
改 `BIDAGENT_PORT`，或查占用：`lsof -i :5210`（Linux）/ `netstat -ano | findstr 5210`（Windows）。

**上传大文件失败（413）**
nginx 的 `client_max_body_size` 没放大，见第 4 节。

**整本生成中途报超时**
nginx `proxy_read_timeout` 太短，调到 600s。同时确认模型接口本身的超时设置。

**登录密码忘了**
停服务，删掉 `data/auth.db`（**会丢失所有账号与企业配置，业务项目还在 app.db**），重启会重新生成管理员。

**生成的内容是模板，没有真实文字**
说明还在 `demo` 模式。去「设置 → 运行模式」切到 `live`，并确认模型已测通。

**检查项全是「待确认」**
正常。`待确认` 表示系统找到了疑点但需要人判断，不是失败。高风险项会单独标红。

**想要语义检索**
默认关闭（纯词法，零费用）。需要时在「设置 → 语义检索开关」里选平台、填 Key、测通后开启。换平台要换对应的 Key。
