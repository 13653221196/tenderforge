# 评分矩阵

## 适用场景
刚拿到招标文件，需要一眼看清「分数怎么分布、哪些分是死的、哪些分能争」。

## 判定逻辑
1. 定位「评分办法 / 评审因素 / 评分标准」章节，止于「技术需求 / 合同条款」。
2. 三种写法都能识别：`（一）技术方案（30分）`、`技术方案 30分`、表格行 `价格分	30	…`。
3. 按关键词把评分项归为价格 / 技术 / 商务三类，并判断性质：
   - **价格分**：按公式计算，看基准价规则；
   - **客观分**：证书、业绩、资质类，材料齐全即可拿满；
   - **主观分**：评委按方案质量打分，是拉开差距的主战场。
4. 校验分项合计是否等于 100 分，不等则提示可能漏识别。

## 输出
- 评分矩阵表（评分项 / 分值 / 归类 / 性质 / 细则）
- 价格分、客观分、主观分的分值分布
- 得分策略提示：客观分先拿满、主观分写足细节

## 边界
分值来自原文，不改写不换算；归类由关键词推断，属速览性质，最终以原文为准。
