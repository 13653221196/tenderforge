# 倾向性条款预警

## 适用场景
判断这个标「是不是为某家量身定做」，决定是否投入资源，或是否需要质疑。

## 判定逻辑
按 8 类常见排他写法逐类扫描，命中即输出原文证据：

| 类型 | 典型写法 | 风险 |
|---|---|---|
| 指定品牌/型号 | 指定品牌、相当于某品牌、原厂授权 | 高 |
| 地域或注册地限制 | 本地注册、在本市设立分支机构、本地业绩 | 高 |
| 业绩门槛偏高 | 近三年 3 个同类业绩、合同额 500 万以上 | 中 |
| 特定认证 | CMMI、涉密、双软、等保 | 中 |
| 注册资本门槛 | 注册资本不低于 1000 万、实缴 | 中 |
| 唯一来源/专利壁垒 | 唯一、独家、专有技术 | 高 |
| 不合理工期或付款 | 5 日内完成、验收后付款 90% | 中 |
| 实质性条款绑定 | 大量★/▲且负偏离即废标 | 低 |

**否定式表述不计入**：出现「不得指定品牌」这类禁止性写法时不判风险。

## 输出
- 风险清单（编号 / 类型 / 等级 / 原文摘录）
- 风险分 0–100，越低越可能排他
- 每类的应对建议（质疑 / 澄清 / 评估放弃）

## 边界
只能识别显性表述；评分细则偏向某方案这类隐性倾向需人工判断。命中不等于违规。
