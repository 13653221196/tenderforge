# 签字盖章核查

## 适用场景
打印装订前最后一遍检查。签章漏一处，可能整本被判无效。

## 判定逻辑
对 8 类固定签章点（投标函、法定代表人身份证明、授权委托书、开标一览表、分项报价表、偏离表、售后承诺、封面）：
1. 在投标文件中定位该文件标题；
2. 检查其后 200 字内是否出现「签字 / 盖章 / 公章 / 签署 / 签章」；
3. 标题缺失 → 缺失；标题在但无签章说明 → 需人工确认。

## 输出
- 签章核查表（文件 / 是否找到 / 判定 / 签章要求）
- 缺失项与人工确认项清单

## 边界
骑缝章、每页小签、印章真伪无法从文本判断，必须看纸质件。
