# 联合体投标核查

## 适用场景
以联合体形式投标时使用。招标文件明确不接受联合体的项目，本技能会直接判为不可用。

## 判定逻辑
1. 先判断招标是否允许联合体（「不接受联合体」直接判不可用）。
2. 在投标文件中逐项查：联合体协议书、牵头人、资质分工、连带责任、各方证照。
3. 协议书与连带责任缺失属高风险。

## 输出
- 联合体核查表（要素 / 情况 / 要求）
- 缺失要素清单

## 边界
协议条款的合法性需法务确认；联合体各方不得再单独参加同一项目。
