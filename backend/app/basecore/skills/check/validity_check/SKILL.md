# 投标有效期核查

## 适用场景
有效期短于要求是典型的「形式性废标」，但很容易被忽略。

## 判定逻辑
1. 从招标文件抽「投标有效期 X 日历天」。
2. 从投标文件投标函段落抽承诺天数。
3. 未承诺 → 高风险；承诺天数 < 要求 → 高风险；≥ 要求 → 通过。

## 输出
- 要求值 / 承诺值对照
- 修正建议（含「有效期至合同签订后 30 天」这类附加要求的提醒）

## 边界
只识别明确写出的天数；「至合同签订之日止」这类表述需人工换算。
