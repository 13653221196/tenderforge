# 文件完整性核查

## 适用场景
投标文件装订前的整本体检，防止漏掉整份附件。

## 判定逻辑
1. 必备文件清单（投标函、开标一览表、分项报价表、法人证明、授权委托书、资格证明、技术/商务偏离表、售后承诺），只保留招标文件实际要求的项。
2. 逐项在投标文件中查标题。
3. 扫描章节编号（第X章 / 一、 / 1.1），统计标题数量与重复数。
4. 无编号体系时提示补齐。

## 输出
- 文件完整性表（文件 / 有无）
- 缺失项（高风险）
- 章节数与重复标题提示

## 边界
按标题匹配；附件另册装订或标题写法特殊时可能漏判，需人工过一遍目录。
