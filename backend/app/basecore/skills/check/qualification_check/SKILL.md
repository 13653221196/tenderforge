# 资格条件核查

## 适用场景
投标前确认「资格这一关能不能过」。资格性条款缺一项即可否决，属于一票否决区。

## 判定逻辑
1. 定位「资格要求 / 合格投标人 / 资格审查」章节。
2. 按编号或「应当/必须/具备/提供」拆成条目。
3. 每条做实体识别（营业执照、资质证书、社保、财务报告、业绩、授权委托书等 30 类），在投标文件中查找。
4. 数值型要求做量化比较：资质等级（特级>一级>二级>三级）、年限、注册资本。
5. 封装/递交/原件类归为人工核对。

## 输出
- 资格响应对照表（序 / 要求 / 状态 / 判定说明）
- 未见响应清单，按风险排序
- 资格维度得分

## 边界
只判断「文中是否出现」，不核验证书真伪与有效期；等级比较依赖文字中的「一级/二级」表述。
