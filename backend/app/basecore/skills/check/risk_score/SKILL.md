# 综合风险评分

## 适用场景
多本标书横向比较，或投标前判断「这本能不能交」。

## 判定逻辑
七维加权：资格 25、完整性 20、保证金 15、报价逻辑 15、有效期 10、一致性 10、文本规范 5。
每维取对应技能的得分，风险贡献 = (100 − 维度得分) × 权重，总和 × 1.15 封顶 100。

## 输出
- 风险值、等级（低 <30 / 中 30–59 / 高 ≥60）
- 风险分解表（维度 / 权重 / 维度得分 / 风险贡献）
- 优先处理项

## 边界
权重是经验设定，可按企业历史废标原因自行调整。
