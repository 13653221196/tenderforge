# 废标自查清单

## 适用场景
投标文件封装前的最后一道机器检查。

## 判定逻辑
依次跑资格、保证金、有效期、完整性、一致性、文本规范、报价逻辑七项，读取各自结论：
- pass → 通过
- fail → 不通过（进高风险清单）
- warn → 存在待修项
另外固定追加两项人工检查：签章与密封、原件与份数。

## 输出
- 清单表（检查项 / 结论 / 说明）
- 通过率
- 不通过项清单

## 边界
机器只覆盖文本层；密封、骑缝章、原件备查必须人工确认。
