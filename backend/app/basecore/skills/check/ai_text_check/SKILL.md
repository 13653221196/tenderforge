# 文本规范检查

## 适用场景
内容写完了，做最后一轮「低级错误」清扫。占位符残留是最伤专业感的问题。

## 判定逻辑
7 类确定性规则：全角数字、连续标点、中英文标点混用、中英文括号混用、中文间多余空格、占位符残留、重复词。
外加 3 类口径检查：单位混用（万元/元、日历天/天）、自称不统一（我公司/我方/投标人）、对方称谓不统一。

## 输出
- 问题分布表（类型 / 次数 / 示例）
- 高风险项（占位符、全角数字）单独标注

## 边界
只查确定性写法问题；错别字与语句不通需人工或 AI 复核。
