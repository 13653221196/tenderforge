# 贴合度评分

## 适用场景
想知道「这本标大概能得多少分」，以及「分该往哪补」。

## 判定逻辑
1. 复用评分矩阵得到各评分项与分值。
2. 按性质给不同测算方式：
   - 价格分：按基准价规则给经验系数；
   - 客观分：统计评分细则关键词在投标文件中的命中率；
   - 主观分：给经验系数（有正文 0.7，无正文 0.5）。
3. 汇总预估得分与覆盖率。

## 输出
- 贴合度测算表（评分项 / 分值 / 预估得分 / 依据）
- 总分与覆盖率
- 优先补强建议

## 边界
系数是经验值，不是评分预测；用于排序与决策，不构成得分承诺。
