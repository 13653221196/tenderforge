# 投标保证金核查

## 适用场景
保证金是废标高发项：金额错、形式不符、到账晚，都可能直接出局。

## 判定逻辑
1. 从招标文件中抽出保证金金额（支持 ¥/元/万元/中文大写）、可接受形式（电汇、保函、保险、支票）、递交截止时间。
2. 在投标文件中查找同额金额（允许 2% 以内四舍五入差异，超出即判不一致）。
3. 检查是否出现保证金相关表述；检查投标采用的形式是否在招标允许范围内。
4. 检查是否写明递交时间。

## 输出
- 保证金对照表（金额 / 形式 / 递交截止）
- 不一致项与修正建议

## 边界
只能核对文本表述；到账时间、保函真伪需人工核实。
