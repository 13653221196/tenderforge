# 报价逻辑闭环

## 适用场景
报价表做完后的算术体检。大小写不一致、分项合计对不上，都可能被认定报价不唯一。

## 判定逻辑
1. 抽「小写」「大写」金额，折算后比对（容差 1 元）。
2. 抽三段式表格行（名称 / 数量 / 单价 / 金额），校验 `数量 × 单价 = 金额`。
3. 找合计/总计/小计行，与投标函小写金额比对。

## 输出
- 报错项列表（含算式与差额）
- 通过项确认

## 边界
只处理结构清晰的报价表；合并单元格、跨页表可能识别不全。
