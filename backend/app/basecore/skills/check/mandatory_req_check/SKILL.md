# 实质性要求对照表

## 适用场景
需要向评委证明「每条强制要求我们都响应了」，同时自查有没有漏项。

## 判定逻辑
1. 复用「实质性条款提取」得到条款清单。
2. 每条条款做实体/数值判定，给出已响应 / 未见响应 / 人工核对。
3. 未见响应即高风险——★/▲ 条款负偏离通常直接废标。

## 输出
- 实质性要求响应表（序 / 条款 / 状态 / 说明）
- 未见响应清单

## 边界
输出可直接作为投标文件响应表底稿，但「响应/偏离」的措辞需按招标格式调整。
