# 电子投标提交核查

## 适用场景
在交易平台上传投标文件前逐项确认。这一环节无法从文档内容判断，因此输出的是核对清单而非结论。

## 核对项
1. CA 数字证书在有效期内，且与报名主体一致
2. 电子签章已完成，签章位置正确
3. 文件格式符合平台要求
4. 单文件/单包大小不超上限
5. 在截止时间前完成上传，预留解密时间
6. 加密方式与开标解密一致，密码由投标人保管
7. 保证金按平台渠道缴纳并已到账
8. 平台在线填报的开标一览表与投标文件一致

## 输出
- 核对清单（环节 / 要求）
- 识别到的交易平台名称（如有）

## 边界
通用清单，具体以平台操作手册为准。
