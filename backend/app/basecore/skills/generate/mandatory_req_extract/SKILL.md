# 实质性条款提取

## 适用场景
准备「实质性要求响应表」之前，先把散落在全文的强制条款捞干净。

## 判定逻辑
1. **强制档**：`★` / `▲` 开头的整行条款。
2. **实质性档**：「实质性要求 / 符合性审查」章节内，含「必须 / 不得 / 应当 / 否决 / 无效」的句子。
3. **一般约束档**：正文中含「必须 / 应当 / 不得 / 严禁 / 须」的句子。
4. 用 2-gram 相似度去重（阈值 0.82），避免同一句被反复抽取。

## 输出
- 清单表（档位 / 条款内容 / 原文位置），按档位排序
- 条款总数与强制条款数
- 条款过多时的分级处理建议

## 边界
纯文本正则抽取，不含语义理解；符号在扫描件中可能丢失，需人工补一次。
