# 标书结构模板

## 适用场景
从零开始搭标书，或检查现有目录是否漏章。

## 判定逻辑
按招标正文关键词命中数判定项目类型（信息化 / 货物 / 工程 / 服务 / 运维），套用对应五套结构模板之一。章节顺序遵循评委翻阅习惯：**资格与商务在前，技术方案在后**。

## 输出
- 章节表（章 / 章节名 / 应含内容 / 写作要点）
- 建议正文规模
- 与招标文件「投标文件组成」对齐的提醒

## 边界
模板是通用骨架，必须逐项替换为招标文件要求的章节名；不同行业监管要求可能另有规定。
